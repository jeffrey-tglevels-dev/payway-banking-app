Idea: Create a banking application.

v1 must include:
1)registeration and login.
2)operations: check balance
              transfer money
3)suitable frontend(react app)

Further version are inteded to make the application production optimized.Read roadmap.md for further details.

Project uses:
Java 25
SpringBoot
MySQL(using docker)
React.js

Dependencies include;
Spring Web / Web MVC - Lets users communicate with your application through HTTP APIs
Spring Data JPA	- Helps your Java application read and write database records
MySQL Driver - Allows Java to communicate with your MySQL database
Spring Security - Provides tools for authentication and authorization
Validation - Checks whether incoming data is valid
Flyway Migration - Tracks database structure changes
Lombok - Reduces repetitive Java code
Spring Boot Actuator - Provides application health and monitoring information
Spring AI(Open AI)

Project uses Package by Feature code management.
